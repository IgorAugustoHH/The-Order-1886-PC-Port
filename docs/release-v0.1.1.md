TOport v0.1.1: launcher em inglês, menu só no Insert e aviso de versão nova. / Launcher in English, menu on Insert only and update notice.

### Novo / New
- **Launcher e menu do jogo em inglês:** escolha Português ou English em *Jogo e idioma*. / **Launcher and in-game menu in English:** pick Português or English in *Game & language*.
- **Aviso de versão nova:** o launcher mostra um botão quando sai um release mais novo. / **Update notice:** the launcher shows a button when a newer release is out.
- **Banner no launcher** desde a primeira abertura, antes de escolher a pasta do jogo. / **Launcher banner** from the first start, before choosing the game folder.

### Corrigido / Fixed
- **Select volta a ser do jogo** (modo foto/touchpad): o menu do TOport abre só com **Insert**. / **Select belongs to the game again** (photo mode/touchpad): the TOport menu opens with **Insert** only.
- O pacote agora se chama sempre **`TOport-Windows.zip`**. / The package is now always named **`TOport-Windows.zip`**.

### Se travar / If it crashes
Abra uma [issue](https://github.com/IgorAugustoHH/The-Order-1886-PC-Port/issues) com o arquivo `last_run.log` da pasta do TOport, sua placa de vídeo, driver e RAM, e onde aconteceu. Deixe o arquivo de paginação do Windows num SSD. / Open an issue with `last_run.log` from the TOport folder, your GPU, driver and RAM, and where it happened. Keep the Windows page file on an SSD.

Requer o seu próprio dump de The Order: 1886 (CUSA00785) **versão 01.02**. Nenhum arquivo do jogo incluído. / Requires your own The Order: 1886 dump (CUSA00785) **version 01.02**. No game files included.
